# Pitchstone OS — Development Guide

## Current Stage

We are in **Phase 0 / early Phase 1**: defining the system, design language, packaging strategy, and visual foundations.

There is not yet a bootable ISO. That is the next major milestone.

## Repository Layout

- `docs/` — Vision, strategy, design, roadmap
- `themes/` — Plasma color schemes, future global themes, wallpapers
- `packaging/` — Meta-packages, menu organization, Calamares branding
- `scripts/` — Helper scripts (BlackArch enable, future build scripts)

## How to Help Right Now

1. **Design** — Critique and improve the color scheme, layout proposals, wallpaper direction
2. **Packaging** — Help finalize exact package names for `pitchstone-security-core` against current Arch + BlackArch
3. **Testing** — Once we have a test ISO or live environment, test the theme and layout
4. **Documentation** — Improve clarity and completeness

## Build Philosophy

- Prefer clean, maintainable solutions over hacks
- Arch compatibility is important — users should still feel at home with the wider Arch ecosystem
- Visual quality and performance are non-negotiable
- Security tools should feel integrated, not bolted on

## Next Major Milestone

A working live ISO that boots into the Pitchstone look with the core theme applied and basic meta-packages available.
