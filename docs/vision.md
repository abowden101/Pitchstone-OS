# Pitchstone OS — Vision

## The Problem

- Kali Linux is extremely powerful for security work but its desktop experience is functional, not delightful.
- Beautiful modern Linux desktops (Garuda, elementary, deepin, etc.) usually treat security tooling as an afterthought.
- Users who need serious security capabilities often end up dual-booting or living in a less enjoyable environment.

## The Goal

Create a single system that is:

1. **As capable as Kali** for offensive security, defensive hardening, and forensics.
2. **As pleasant (or more pleasant) than macOS / Windows** for daily use.
3. **Hybrid in interface** — not a pure clone of either, but a thoughtful blend that feels original and superior in fluidity and productivity.

## Core Principles

- **Defaults matter more than options.** Ship something beautiful and usable immediately.
- **Security should not feel like a compromise.** Tools are present and integrated, not bolted on.
- **Motion, glass, and polish are features**, not decoration.
- **Performance is non-negotiable.**
- **Long-term maintainability.** Prefer clean packaging and reproducible builds over hacky one-offs.

## Target Users (Initial)

- Security professionals and enthusiasts who want a daily driver.
- Network / security engineers (the builder’s own profile).
- Power users who like Arch-style modernity but want strong security tooling pre-curated.
- People tired of the "ugly but powerful" or "pretty but weak" trade-off.

## Success Criteria (Early)

- Boots into a hybrid Plasma layout that feels intentional and premium.
- Security tools are one click / one command away and well organized.
- System feels faster and more fluid than stock Kali or generic Arch + Plasma.
- Someone who has never used Linux can still find their way around without frustration.
