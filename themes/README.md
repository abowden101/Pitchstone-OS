# Pitchstone OS Themes

This directory will hold:

- Plasma global themes / color schemes / layouts
- Icon themes
- Wallpapers
- Cursor themes (if custom)
- SDDM / login theme
- Calamares branding

---

## Wallpaper Direction ("Pitchstone" series)

**Concept**: Abstract geological / mineral textures that feel like dark stone with subtle light catching edges and fractures. Supports glass UI overlays extremely well.

Desired characteristics:
- Deep, desaturated base tones (charcoal, deep slate, near-black)
- Subtle cool light refraction or soft geometric light
- Low visual noise so panels and windows remain readable
- 4K+ resolution
- Both pure abstract and lightly photographic mineral looks

Working series names:
- Pitchstone Core
- Obsidian Fracture
- Basalt Flow
- Dark Mineral
- Fracture Light

We will generate and curate a set of 6–8 high-quality wallpapers as the default collection.

---

## Icon Direction

- Start from a strong modern base (candidates: Papirus, Tela, or a refined Fluent-inspired set)
- Customize colors to match our accent (`#5B8CFF`)
- Ensure security tools have clear, professional icons
- Keep a consistent rounded geometric language
