# Pitchstone Wallpapers

## Series Concept: "Pitchstone"

Abstract geological / mineral textures that feel like dark volcanic stone and obsidian with subtle light catching the fractures and edges.

**Design goals:**
- Deep, desaturated charcoal and near-black bases
- Cool light refraction (subtle blue / teal edge light)
- Low visual noise so glass panels remain perfectly readable
- Premium, calm, powerful feeling
- Works extremely well with the Pitchstone Dark color scheme and glass UI

## Planned Set (v1)

1. **Pitchstone Core** — Deep fractured dark stone, soft central light
2. **Obsidian Fracture** — Sharp crystalline breaks with cool edge lighting
3. **Basalt Flow** — Smooth flowing dark mineral with subtle motion feel
4. **Core Light** — Minimal, almost pure dark with a single refined light accent
5. **Ash Vein** — Delicate lighter veins running through deep stone
6. **Night Mineral** — Rich, slightly more detailed texture for variety

All wallpapers will be delivered in 4K (3840×2160) and ultrawide variants where possible.
