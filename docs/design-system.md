# Pitchstone OS — Design System (Draft)

## Guiding Aesthetic

**Hard + Fluid.**  
Stone-like solidity in structure, liquid motion and glass in surface.

## Core Keywords

- Dark-first (excellent light mode later)
- Glass / translucency with depth
- Refined, not flashy
- High contrast where needed for usability
- Smooth, purposeful motion (no gratuitous effects)

## Interface Direction (Hybrid)

- **Primary layout experiments**:
  - Option A: Top panel (status + global menu feel) + bottom dock (macOS influence)
  - Option B: Refined bottom taskbar with strong start launcher + floating dock elements
  - Goal: Something that feels neither pure Windows nor pure Mac, but better than both for power users

## Color Direction (Initial)

- Deep charcoal / near-black backgrounds
- Cool accent (slate, deep teal, or sharp indigo — TBD)
- Subtle warm highlights for secondary actions
- High-quality wallpaper set that supports glass overlays
