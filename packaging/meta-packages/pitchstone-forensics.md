# pitchstone-forensics

Focused on digital forensics, incident response, and memory analysis.

## Key Tools

- volatility3
- autopsy / sleuthkit
- binwalk, foremost, scalpel, bulk_extractor
- plaso / log2timeline
- regripper / yarp (Windows registry)
- memory acquisition helpers
- disk imaging tools (dc3dd, dcfldd, etc.)
- network forensics extras
- steganography tools

This group can be installed independently or as part of the fuller security sets.
