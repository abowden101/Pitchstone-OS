# pitchstone-global (Plasma Global Theme)

This will become the installable package that applies the full Pitchstone look.

## Planned contents

- Color scheme: PitchstoneDark
- Plasma style / desktop theme
- Window decorations (light, modern)
- Layout scripts or configuration for the hybrid Dock profile
- Optional Taskbar profile
- Cursor theme (if we ship one)
- Splash screen (optional)

## Installation target

```bash
pacman -U pitchstone-plasma-theme-*.pkg.tar.zst
# or once in a repo:
pacman -S pitchstone-plasma-theme
```

After install, the theme should be selectable in System Settings and preferably set as default on first boot of the live ISO and installed system.

## Status

Color scheme exists. Full global theme package structure and layout configs are the next concrete work items.
